# Разработка ядра алгоритма расчета материалов

`calculate_material_amount` считает сырьё на партию и берёт коэффициент типа продукции и процент брака материала из справочников БД.

На одну единицу: `param_1 × param_2 × коэффициент`. На партию это умножается на `quantity`, затем на `(1 + процент брака / 100)`. Результат округляется вверх через `ceil`.

Если тип не найден, параметры не положительные или количество ≤ 0, метод возвращает `-1` и не прерывает программу.

## Справочники

| Тип продукции | Коэффициент |
| --- | --- |
| 1 Ламинат | 2.35 |
| 2 Паркетная доска | 4.34 |
| 3 Пробковое покрытие | 1.5 |

| Тип материала | Брак, % |
| --- | --- |
| 1 Древесноволокнистая плита | 0.8 |
| 2 Мебельный щит | 0.3 |
| 3 Фанера | 1.0 |

Пример: пробковое покрытие и фанера, `param_1=2`, `param_2=3`, `quantity=4` → 37.
