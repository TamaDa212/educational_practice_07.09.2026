# Разработка интерфейса истории реализации продукции

`PartnerHistoryWindow` показывает, какую продукцию, в каком количестве и когда отгрузил выбранный партнёр.

С главной формы менеджер выбирает строку партнёра и нажимает «История продаж». В окно передаётся `partner_id`. Заголовок: `CRM: История реализации продукции — [Название партнера]`. Таблица строится SQL-запросом с `JOIN`: наименование продукции, количество (шт.), дата продажи в формате `ДД.ММ.ГГГГ`.

## Запуск

```bash
cd "Учебная практика 28.09.2026/Разработка интерфейса истории реализации продукции"
python3 app.py
```

Откроется `http://127.0.0.1:8771/`.
