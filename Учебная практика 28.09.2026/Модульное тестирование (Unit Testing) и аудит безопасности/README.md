# Модульное тестирование и аудит безопасности

Пять unit-тестов метода `calculate_material_amount` лежат в `test_material_units.py`: обычный расчет, округление вверх, неизвестный тип, отрицательный размер, нулевое и отрицательное количество.

SQL в практике передаёт значения параметрами `?`, без склейки строк. Проверка — `security_audit.py`.

Исключения пишутся в `app.log`: дата, время и текст ошибки.

## Проверка

```bash
cd "Учебная практика 28.09.2026/Модульное тестирование (Unit Testing) и аудит безопасности"
python3 demo.py
python3 -m pytest
```
