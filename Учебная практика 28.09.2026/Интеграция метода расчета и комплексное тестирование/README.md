# Интеграция метода расчета и комплексное тестирование

Калькулятор заказа вызывает `calculate_material_amount` и выводит результат на форму. Если метод вернул `-1` (отрицательный размер, количество ≤ 0 или неизвестный ID типа), страница не падает и показывает, что исправить.

## Запуск

```bash
cd "Учебная практика 28.09.2026/Интеграция метода расчета и комплексное тестирование"
python3 app.py
```

Откроется `http://127.0.0.1:8772/`.

Пример: тип продукции 3, тип материала 3, количество 4, параметры 2 и 3. На форме будет «Необходимо сырья: 37 ед.».

## Тесты

python3 demo.py
