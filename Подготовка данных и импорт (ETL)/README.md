# Подготовка данных и импорт (ETL)

## Кратко

Скрипт `etl.sql` загружает очищенные данные в таблицы `partners`, `products` и `shipments`.

## Этапы

1. **Extract** — исходники в `data/raw`
2. **Transform** — результат очистки в `data/clean`
3. **Load** — вставка через `etl.sql`

## Очистка

- пробелы в названиях компаний
- единый формат даты `YYYY-MM-DD`
- пустые значения записаны как `NULL`
- продажа с несуществующим партнёром (`sale_id=104`) не загружается

## Результат

- 3 партнёра
- 3 товара
- 4 отгрузки
