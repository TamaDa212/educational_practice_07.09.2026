# Разработка проверочных SQL-запросов (Эмуляция бэкенда)

## Цель

Показать, что схема БД закрывает требования заказчика: просмотр партнёров, изменение данных и история отгрузок.

## Что нужно заранее

1. Создать таблицы из `schema.sql` (папка «Проектирование базы данных…»).
2. Загрузить данные из `etl.sql` (папка «Подготовка данных и импорт…»).

## Шаги проверки

1. Открыть `queries.sql`.
2. Выполнить **запрос 1** — список партнёров и число доставок.
3. Выполнить **запрос 2** (`BEGIN … COMMIT`) — добавить партнёра и тестовую отгрузку.
4. Выполнить **запрос 3** — история отгрузок партнёра за период.
5. Убедиться, что результаты соответствуют данным в таблицах.

## Содержимое queries.sql

| Запрос | Назначение |
|---|---|
| 1 | Партнёры + `COUNT` доставок (`LEFT JOIN`) |
| 2 | Транзакция: новый партнёр и первая доставка |
| 3 | История отгрузок партнёра за даты |

## Запуск (пример)

```bash
sqlite3 mydb.db < queries.sql
```
