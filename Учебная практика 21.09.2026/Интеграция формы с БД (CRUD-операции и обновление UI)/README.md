# Интеграция формы с БД (CRUD-операции и обновление UI)

Форма работает в двух режимах. «Добавить» открывает пустую карточку и делает `INSERT`. Клик или двойной клик по строке партнёра открывает карточку с данными из БД и при сохранении делает `UPDATE`. После успеха окно закрывается, таблица на главной форме читается заново из базы.

Ссылочная целостность на уровне кода: `UPDATE` только существующего `partner_id`, первичный ключ не меняется, удаление партнёра с историей продаж запрещено, `PRAGMA foreign_keys = ON`.

## Запуск

```bash
cd "Учебная практика 21.09.2026/Интеграция формы с БД (CRUD-операции и обновление UI)"
python3 app.py
```

Откроется `http://127.0.0.1:8769/`.
