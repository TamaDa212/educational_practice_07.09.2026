# Проектирование многооконной архитектуры и навигации

CRM больше не одностраничное. Менеджер ходит по экранам через стек навигации: список → карточка партнера → история продаж. Кнопка «Назад» не закрывает приложение и не сбрасывает выбранного партнёра.

## Экраны

- `CRM: Список партнеров и скидок` — `/`
- `CRM: Карточка партнера` — `/partner/4`
- `CRM: История продаж` — `/partner/4/history`
- `CRM: Партнер не найден` — неверный id, без падения

Состояние: `Navigator.selected_partner_id` сохраняется после возврата к списку. Партнёр без продаж (`ООО "Новый Контур"`) открывает пустую историю и скидку 0%.

## Запуск

```bash
cd "Учебная практика 21.09.2026/Проектирование многооконной архитектуры и навигации"
python3 app.py
```

Откроется `http://127.0.0.1:8767/`.
