# Обработка исключений и интерактивные уведомления (UX/UI)

Система не падает при ошибке ввода: проверка идёт в `try...except` до записи в БД. Пользователь видит системное диалоговое окно MessageBox с заголовком, пиктограммой и текстом, что делать дальше.

## Диалоги

- **Ошибка** — нецелое или отрицательное число в рейтинге, пустые наименование/email, недоступна СУБД. Иконка крестика.
- **Предупреждение** — «Назад» или «Отмена», если поля уже меняли. Несохранённые данные будут потеряны. Иконка восклицательного знака.
- **Информация** — партнёр успешно добавлен или сохранён. Иконка инфо-значка.

## Запуск

```bash
cd "Учебная практика 21.09.2026/Обработка исключений и интерактивные уведомления (UX/UI)"
python3 app.py
```
