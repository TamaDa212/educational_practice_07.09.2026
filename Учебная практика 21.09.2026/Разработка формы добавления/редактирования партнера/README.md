# Разработка формы добавления/редактирования партнера

`PartnerEditWindow` — отдельный экран карточки партнёра. Поля соответствуют ТЗ: текст, ComboBox типа, целое неотрицательное число рейтинга, адрес, ФИО директора, телефон и email с подсказками формата.

## Поля

- Наименование — текстовое поле
- Тип партнера — строго `select` / ComboBox: ЗАО, ООО, ИП, ТК, ТД, ПАО, ОАО, АО
- Рейтинг — целое неотрицательное число (`min=0`, `step=1`)
- Адрес — текстовое поле
- ФИО директора — текстовое поле
- Телефон — плейсхолдер `+7 (999) 123-45-67` и tooltip с маской
- Email — плейсхолдер `name@company.ru` и tooltip с форматом

При редактировании ID партнёра передаётся между окнами скрытым полем `partner_id` и стеком навигации.

## Запуск

```bash
cd "Учебная практика 21.09.2026/Разработка формы добавления/редактирования партнера"
python3 app.py
```

Откроется `http://127.0.0.1:8768/`.

- Добавление: `/partner/new`
- Редактирование: `/partner/4/edit`
