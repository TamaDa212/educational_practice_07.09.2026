# Наполнение интерфейса, отладка и стресс-тестирование

Финальная сборка CRM: список на экране берётся из подзадания 2 (`list_partners_with_discount` → `get_partner_with_discount`), скидка считается автоматически.

## Что проверяется

- Партнёр без продаж (`ООО "Новый Контур"`): `SUM(quantity)` даёт `NULL`, на карточке **0%**, без `TypeError`
- Контакты с экрана — те же, что в БД: email, телефон, рейтинг
- Стресс: 250 партнёров без истории продаж и 50 повторных отрисовок списка

## Запуск приложения

```bash
cd "Учебная практика 14.09.2026/Наполнение интерфейса, отладка и стресс-тестирование"
python3 app.py
```

Откроется `http://127.0.0.1:8766/`. Стили и логотип — из папки UI.
