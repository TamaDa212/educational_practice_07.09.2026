# Разработка интерфейса (UI) по руководству по стилю

Экранная форма CRM для менеджера: список партнёров и скидок. Внешний вид карточек совпадает с `resources/Screenshot_2.png`.

## Что сделано по ТЗ

- Заголовок окна и страницы: **CRM: Список партнеров и скидок**
- Иконка приложения в углу окна — `resources/app_icon.png` (вкладка браузера и шапка окна)
- Логотип компании на главной форме — `resources/company_logo.png`
- Карточки партнёра: тип | наименование, директор, телефон, рейтинг, скидка справа
- Шрифт Arial, белый фон, серые рамки и белые кнопки — как на руководстве по стилю

Данные и процент скидки берутся из заданий 14.09.2026: таблица `partners` + `calculate_partner_discount`.

## Запуск

```bash
cd "Учебная практика 14.09.2026/Разработка интерфейса (UI) по руководству по стилю"
python3 app.py
```

Откроется `http://127.0.0.1:8765/`. Остановка: Ctrl+C.

## Тесты

python3 -m venv .venv

pip install -r requirements.txt
