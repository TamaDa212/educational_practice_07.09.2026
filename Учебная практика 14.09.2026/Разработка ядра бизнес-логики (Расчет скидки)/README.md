# Учебная практика 14.09.2026

Индивидуальный процент скидки партнёра по суммарному объёму купленной продукции.

## Правило расчёта

| Объём, ед. | Скидка |
|---|---|
| меньше 10 000 | 0% |
| от 10 000 до 49 999 | 5% |
| от 50 000 до 299 999 | 10% |
| от 300 000 и больше | 15% |

Функция: `calculate_partner_discount(total_quantity: int) -> int`

## Файлы

- `partner_discount.py` — расчёт скидки
- `test_partner_discount.py` — unit-тесты пограничных значений
- `requirements.txt` — pytest и coverage

## Запуск тестов

```bash
cd "Учебная практика 14.09.2026/Разработка ядра бизнес-логики (Расчет скидки)"
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pytest
```

Покрытие должно быть 100%. Проверяются границы: `9999`, `10000`, `49999`, `50000`, `299999`, `300000`.
